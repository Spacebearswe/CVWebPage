# CV Web Page

A clean, responsive personal curriculum vitae website designed to showcase professional experience, skills, education, and contact information in a modern and easy-to-read format.

## Overview

This project is a lightweight static website for presenting a CV or portfolio online. It is suitable for personal branding, job applications, freelance profiles, and portfolio showcases.

## Features

- Responsive single-page layout
- Professional CV sections for summary, experience, education, and skills
- Clean visual design with modern typography
- Mobile-friendly structure
- Easy to customize with your own content and branding
- Static site setup with no heavy framework required

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/CVWebPage.git
   ```
2. Navigate to the project folder:
   ```bash
   cd CVWebPage
   ```
3. Open `index.html` in your browser, or run a local web server:
   ```bash
   python -m http.server 8000
   ```
4. Visit `http://localhost:8000` in your browser.

## Customization

Update the following sections in the main HTML file:

- Personal information
- Biography / profile summary
- Work experience
- Education
- Skills
- Contact details

Adjust colors, spacing, and typography in the stylesheet to match your personal brand.
